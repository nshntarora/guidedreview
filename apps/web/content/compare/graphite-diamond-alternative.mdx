# Guided Review vs Graphite: a walkthrough or team review tools (2026)

Pick Guided Review if you're an engineer who wants to read a GitHub PR or local diff with your own AI provider. Pick Graphite if you need automated review comments and suggested changes as part of a broader team workflow. The deciding difference is the work you want the tool to do: organize your reading, or provide review feedback and team tools. Guided Review won't replace a merge queue or review rules. If those are why you use Graphite, keep it. The choice flips toward Guided Review when your unmet need is a reading session you control.

I built Guided Review, and Guided Review publishes this page. Yes, it's biased. Product claims below link to sources checked on **2026-10-08**; prices and features can change.

Graphite describes AI Reviews as “Instant AI code review.” ([Vendor source](https://graphite.com/features/ai-reviews), checked 2026-10-08.)

## Key takeaways

- Guided Review helps you follow the real diff and leaves feedback to you.
- Graphite wins on automated findings and suggested fixes.

## Choose Guided Review when

You want an ordered view of a PR or local diff, will write your own comments, and prefer configuring your own model provider.

## Choose Graphite when

You need automated comments and suggested changes, or use Graphite for team review rules and its merge queue. Guided Review does not replace those jobs.

## Workflow: a reading tool will not replace a team process

For a team already using Graphite to move PRs through review, switching the reading interface is only one part of the job. I'd separate that from changing how the team ships.

Graphite's AI Reviews provides comments and suggested changes [C1](#source-c1). Guided Review groups related hunks so a person can read the implementation [G1](#source-g1). A person still has to decide what belongs in the change, whether the default is right, and whether a test proves the behavior they need.

Consider a new default page size. You need to follow the value from the API type through validation to the query builder. A test for an explicit page size doesn't answer what happens when the caller omits it. A reading path can help you keep that question in view.

But if your team also relies on a merge queue or review automations, that reading path doesn't replace them. Graphite lists those tools in its Team plan [C2](#source-c2). Keep the comparison tied to the work you need. You can prefer one diff view without wanting to replace the rest of your process.

## Pricing: identify the plan you would actually use

An engineer trying a reading tool and a team buying a review platform have different cost questions. I'd start with the plan and the workflow, then estimate the bill.

Guided Review is free today. AI usage belongs to your provider account [G5](#source-g5). One structuring request can become several model calls when a diff needs multiple chunks. Reading units, searching, and writing notes don't keep adding calls [G1](#source-g1). The cost depends on the diff and model you choose.

Graphite's checked plan prices are in the table above [C2](#source-c2). The free plan's limited AI access and the paid plan's team tools serve different uses. A small team should check the current plan details against its own needs rather than assume the free option covers its review process.

There's no measured savings claim here. If you stop paying for tools that ran part of your process, someone or something has to do that work. Guided Review can help with reading code; its product fee doesn't tell you what replacing a team workflow would cost.

## Setup and data: check the host and the request

You can try a Guided Review walkthrough without moving a repository or changing its PR history. That makes an individual trial small. It doesn't make every change to a team's review process small.

The extension runs on github.com PRs. The CLI reads a local branch, working tree, or commit and opens a browser UI [G2](#source-g2), [G3](#source-g3). Both can show a file-by-file view without an AI call. For grouping and commentary, configure a provider and send the diff prompt to it. There is no Guided Review backend receiving that prompt [G4](#source-g4).

Graphite's AI Reviews starts by connecting GitHub [C1](#source-c1). I'd check the permissions and team settings during evaluation. This page doesn't establish a processing region or retention term from its feature page. Those gaps should become vendor questions if they affect your purchase.

For Guided Review, the same check includes your model provider. A local server and a remote model can be part of one workflow. Knowing where the interface runs is useful, but it doesn't tell you where the code goes for inference.

## Switching

There's no migration tool for Graphite rules, queue settings, comments, or history. Trying Guided Review means installing a host and, for AI, configuring a provider [G2](#source-g2), [G3](#source-g3). Existing PR discussions can stay in GitHub.

Replacing Graphite's team workflow is a larger change. Guided Review won't run its automated review rules, proposed fixes, or merge queue. Keep those dependencies in place while trying a walkthrough. Removing the extension or stopping the CLI reverses the trial; it doesn't reverse a submitted GitHub review. Copy needed CLI notes before ending its session [G3](#source-g3).

## Recommendation

I'd pick Guided Review for an individual reading session with my own provider. I'd pick Graphite for automated feedback and team review tools. The choice flips when the problem moves from understanding a diff to running a shared review process.
