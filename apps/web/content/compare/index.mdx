## Compare AI code review tools by the work you need done

Start with the output. Do you want generated findings to assess, an ordered path through the diff, or help moving pull requests through a team process? These tools overlap, but switching between them can leave a job uncovered.

Guided Review publishes this comparison. I built it for the person reading the code. The table links to each vendor's documentation; it doesn't rank bug detection or claim one interface is faster.

### Match the tool to the review question

- **“I need to understand this implementation before approving it.”** Try Guided Review on a diff you know. Follow the contract, callers, and tests across review units. Compare that reading experience with CodeRabbit's walkthrough and Change Stack if you already use them.
- **“I need findings when a PR changes.”** Evaluate CodeRabbit, Graphite AI Reviews, or Copilot code review. Guided Review leaves findings and review comments to you.
- **“I need a merge queue or a stacked-PR workflow.”** Evaluate the team tools alongside the review interface. A Guided Review overlay doesn't replace those parts of the process.
- **“I want to check my local changes before opening a PR.”** Start with the [local-review example](/guides/review-local-changes-before-pr#try-a-branch-with-an-uncommitted-test). Compare branch, staged, and working-tree scopes before choosing whether to request AI structure.

You can keep an automated reviewer and use Guided Review for your own reading pass. A bot's findings and your understanding of the implementation answer different questions.

### Check where the code goes

With Guided Review, the extension talks to GitHub and your configured AI provider. The CLI runs locally and sends a diff prompt to that provider when you request AI structuring. There is no Guided Review backend receiving your code or keys. [Storage and request details](/docs/privacy-and-data) matter more than calling the tool “local.”

For the other tools, check their processing paths and your organization's settings: [CodeRabbit architecture](https://docs.coderabbit.ai/overview/architecture), [Graphite's privacy policy](https://graphite.com/privacy), and [Copilot responsible use](https://docs.github.com/en/copilot/responsible-use/agents). Ask the vendor about any processing or retention details the linked pages leave unanswered. This table doesn't establish a security ranking or promise offline inference.

### Try one change before changing the team's process

Pick a patch with a requirement you can state in one sentence. Check whether you can follow the changed behavior, identify what the tests prove, and leave feedback another engineer can act on. Use the same patch for each tool; record setup and provider usage separately from time spent reading.

The [CodeRabbit comparison](/compare/coderabbit-alternative#try-a-real-public-pull-request) includes a pinned public PR you can reproduce. For a small patch whose behavior is already obvious, the normal GitHub diff may be enough.
