# Introduction

Guided Review turns a diff into an ordered walkthrough — schema first, then logic, call-sites, and tests — so you can review with intent instead of scrolling a raw change list. Same engine for GitHub pull requests and local git work. For the motivation behind that, see [Why](/docs/why).

## What is Guided Review?

Guided Review is two surfaces on one review engine:

| Surface              | What you review                       | How you start                                      |
| -------------------- | ------------------------------------- | -------------------------------------------------- |
| **Chrome extension** | Pull requests on `github.com`         | **Start Guided Review** on the PR page             |
| **CLI**              | Local branch, commit, or working tree | `npx @guided-review/cli` → browser UI on localhost |

On either path:

1. The real unified diff is parsed into files, hunks, and lines
2. With **[your AI provider](/docs/configure-provider)** configured (Anthropic, OpenAI, or Grok), the model returns **[review units](/docs/how-it-works)** — logical groups of hunks with short commentary
3. You step through those units in a keyboard-first overlay; the code you see always comes from the real parsed diff

Without a key you still get a file-by-file walk. The model plans structure and commentary only — it never invents the code lines. For what leaves your machine, see [Privacy & data](/docs/privacy-and-data).

The extension can optionally [submit reviews](/docs/submit-review) to GitHub. The CLI keeps line notes local and can [Generate Prompt](/docs/generate-prompt) for a coding agent instead.

## Quick start

Start at [Install](/docs/install) for both hosts, then:

**GitHub pull requests**

1. [Install the Chrome extension](/docs/chrome-extension) (or follow [Install](/docs/install)).
2. [Configure a provider](/docs/configure-provider) (optional for a file-by-file walk).
3. Open any GitHub pull request and click **Start Guided Review**.
4. Step through the plan — see [Your first review](/docs/first-review).
5. Optionally [draft line comments](/docs/leave-comments) and [submit](/docs/submit-review) (needs [GitHub connected](/docs/connect-github)).

**Local changes**

1. [Install / run the CLI](/docs/install) with Node.js 22+: `npx @guided-review/cli`.
2. Pick a diff scope (branch vs base, uncommitted, or a commit).
3. Optionally hit **Structure with AI**, then walk the units.
4. Full local workflow: [CLI](/docs/cli).

> **Open source.** Guided Review is Apache-2.0. Source and issues live on [GitHub](https://github.com/nshntarora/guidedreview). Stuck? Start with the [FAQ](/docs/faq) or [Troubleshooting](/docs/troubleshooting).
