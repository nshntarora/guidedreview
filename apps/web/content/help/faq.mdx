# FAQ

Short answers to the questions people ask before and after install. Longer how-tos live in the rest of the docs — start from the [Introduction](/docs) if you’re new.

<TocCard toc={toc} />

## How does it work?

[Install the Chrome extension](/docs/install), open a GitHub PR, click **Start Guided Review**. The extension reads the PR diff, calls **[your AI provider](/docs/configure-provider)** for an ordered set of review units (or walks **file by file** if no key is set), and shows them in an overlay mapped back to the real hunks. You step through ([first review](/docs/first-review)), [comment](/docs/leave-comments), and optionally [submit a review](/docs/submit-review). Pipeline detail: [How a review plan works](/docs/how-it-works). Keyboard-first path: [Keyboard shortcuts](/docs/keyboard-shortcuts).

## Do you track anything?

The **extension** does not track review activity and does not talk to Guided Review servers — only GitHub and your AI provider. The **marketing site** uses an analytics service for page views and a few CTA clicks. Full breakdown: [Privacy & data](/docs/privacy-and-data).

## Is it free forever?

Forever is a long time. It’s free while it can be maintained for free. If demand grows and maintenance can’t stay free, something for compensation might show up later. It’s [open source](https://github.com/nshntarora/guidedreview) — you can fork it if you need to. Getting set up costs only your own provider usage ([Configure AI provider](/docs/configure-provider)).

## Will this run up my API bill?

Starting a review with a provider configured makes **one annotate call per diff chunk** — small PRs are usually a single call; large ones are [split by file](/docs/how-it-works#chunking-large-prs) (~60k characters per chunk), so cost scales with diff size and [model](/docs/configure-provider#pick-a-model). A small PR on a cheap model is fractions of a cent; a huge monorepo PR on a frontier model is not.

You’re paying your provider directly — usage shows up on their dashboard, not ours. Guided Review does not meter or resell LLM traffic. Walking units, searching, drafting comments, and submitting to GitHub do **not** call the model again.

## Can I use it without an API key?

Yes, partially. Without a key you still get the overlay, real diff, [file-per-unit plan](/docs/how-it-works#without-a-provider), [diff search](/docs/keyboard-shortcuts#diff-search), and [local draft comments](/docs/leave-comments). You won’t get AI clustering or unit summaries until you [configure a provider](/docs/configure-provider). [Submit](/docs/submit-review) still needs [GitHub connected](/docs/connect-github), not an LLM key.

## Does the AI approve PRs?

No. The model clusters and orders changes and writes short guidance ([How a review plan works](/docs/how-it-works)). You read the code and you [submit](/docs/submit-review) approve / comment / request changes. Take unit summaries with a grain of salt.

## Which AI providers?

Anthropic (Claude), OpenAI, and Grok (xAI). You bring your own API key. Setup and model list: [Configure AI provider](/docs/configure-provider). Connection failures: [Troubleshooting](/docs/troubleshooting#provider-and-api-key).

We’ll keep adding more providers — [request one on the repo](https://github.com/nshntarora/guidedreview), or open a PR that adds yours.

## Do I need GitHub auth?

Not to generate a plan or walk units ([Your first review](/docs/first-review)). Yes, if you want to [submit a review](/docs/submit-review) (line comments and overall decision) from the overlay. [Drafting comments](/docs/leave-comments) works offline of GitHub auth. Scopes, SSO, and disconnect: [Connect GitHub](/docs/connect-github).

## Does it work outside github.com?

The content script targets **`https://github.com/*` only** — public and private repos on github.com, not GitHub Enterprise Server, GHEC enterprise hosts with a different hostname, or other forges. If you need another host, open an issue or PR on the [repo](https://github.com/nshntarora/guidedreview).

## Where is the code?

[github.com/nshntarora/guidedreview](https://github.com/nshntarora/guidedreview) (Apache-2.0). Issues and PRs welcome when something’s wrong or unclear. Load-from-source: [Install → Load unpacked](/docs/install#load-unpacked-development).
