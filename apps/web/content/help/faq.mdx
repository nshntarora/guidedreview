# FAQ

Short answers to the questions people ask before and after install. Longer how-tos live in the rest of the docs.

<TocCard toc={toc} />

## How does it work?

Install the Chrome extension, open a GitHub PR, click **Start Guided Review**. The extension reads the PR diff, calls **your** AI provider for an ordered set of review units, and shows them in an overlay mapped back to the real hunks. You step through, comment, and optionally submit a review. More detail: [How a review plan works](/docs/how-it-works).

## Do you track anything?

The **extension** does not track review activity and does not talk to Guided Review servers — only GitHub and your AI provider. The **marketing site** may include anonymous analytics. Full breakdown: [Privacy & data](/docs/privacy-and-data).

## Is it free forever?

Forever is a long time. It’s free while it can be maintained for free. If demand grows and maintenance can’t stay free, something for compensation might show up later. It’s [open source](https://github.com/nshntarora/guidedreview) — you can fork it if you need to.

## Does the AI approve PRs?

No. The model clusters and orders changes and writes short guidance. You read the code and you submit approve / comment / request changes. Take unit summaries with a grain of salt.

## Which AI providers?

Anthropic (Claude), OpenAI, and Grok (xAI). You bring your own API key. See [Configure AI provider](/docs/configure-provider).

## Do I need GitHub auth?

Not to generate a plan or walk units. Yes, if you want to [submit a review](/docs/submit-review) (line comments and overall decision) from the overlay. See [Connect GitHub](/docs/connect-github).

## Where is the code?

[github.com/nshntarora/guidedreview](https://github.com/nshntarora/guidedreview) (Apache-2.0). Issues and PRs welcome when something’s wrong or unclear.
