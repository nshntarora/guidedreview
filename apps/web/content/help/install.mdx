# Install the extension

Guided Review runs as a Chrome Manifest V3 extension. Install it once, then use it on any `github.com` pull request.

<TocCard toc={toc} />

## Chrome Web Store

1. Open the [Guided Review listing](https://chromewebstore.google.com/detail/guided-review/YOUR_EXTENSION_ID) on the Chrome Web Store.
2. Click **Add to Chrome** and confirm.
3. Pin the extension from the puzzle-piece menu if you want one-click access to options.

> **Store ID placeholder.** If the store link still shows a placeholder ID, use the install button on [guidedreview.com](https://guidedreview.com) or install from source below.

## Load unpacked (development)

For local builds and contributors:

1. Clone the [repository](https://github.com/nshntarora/guidedreview).
2. From the monorepo root, install and build the extension:

```bash
npm install
npm run build:extension
```

3. Open `chrome://extensions`, enable **Developer mode**, and click **Load unpacked**.
4. Select **`apps/extension/dist`** — never a root-level `dist/` if one exists from an older layout.
5. After code changes, run `npm run build:extension` again, then hit **Reload** on the extension card and refresh the GitHub PR tab.

> **Dev HMR.** `npm run dev` / `npm run dev:extension` serves Vite HMR on port **5173**, but Chrome still loads the built files under `apps/extension/dist`. Rebuild (or rely on the dev pipeline that writes there) and reload the extension when behavior looks stale.

## After install

1. Open the extension **Options** page (right-click the extension icon → Options, or open it from `chrome://extensions`).
2. [Configure an AI provider](/docs/configure-provider) and save your API key.
3. Optionally [connect GitHub](/docs/connect-github) if you want to submit reviews from the overlay.
4. Open a PR and follow [Your first review](/docs/first-review).
