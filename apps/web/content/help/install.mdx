# Install the extension

Guided Review runs as a Chrome Manifest V3 extension. Install it once, then use it on any `github.com` pull request. For the “why” and product map, see the [Introduction](/docs).

<TocCard toc={toc} />

## Chrome Web Store

1. Open the <a href={CHROME_WEB_STORE_URL}>Guided Review listing</a> on the Chrome Web Store.
2. Click **Add to Chrome** and confirm.
3. Pin the extension from the puzzle-piece menu if you want one-click access to options.

> **Site shortcut.** On [guidedreview.dev](https://guidedreview.dev), `⌘/Ctrl` + `I` opens the Chrome Web Store listing — see [Keyboard shortcuts](/docs/keyboard-shortcuts#marketing-site).

## Load unpacked (development)

For local builds and contributors:

1. Clone the [repository](https://github.com/nshntarora/guidedreview).
2. From the monorepo root, install and build the extension:

```bash
npm install
npm run build:extension
```

3. Open `chrome://extensions`, enable **Developer mode**, and click **Load unpacked**.
4. Select **`apps/extension/dist`** — never a root-level `dist/` if one exists from an older layout.
5. After code changes, run `npm run build:extension` again, then hit **Reload** on the extension card and refresh the GitHub PR tab.

> **Dev HMR.** `npm run dev` / `npm run dev:extension` serves Vite HMR on port **5173**, but Chrome still loads the built files under `apps/extension/dist`. Rebuild (or rely on the dev pipeline that writes there) and reload the extension when behavior looks stale. More on stale builds: [Troubleshooting](/docs/troubleshooting#load-unpacked-stale-build).

## After install

1. Open the extension **Options** page (right-click the extension icon → Options, or open it from `chrome://extensions`).
2. [Configure an AI provider](/docs/configure-provider) and save your API key.
3. Optionally [connect GitHub](/docs/connect-github) if you want to [submit reviews](/docs/submit-review) from Guided Review.
4. Open a PR and follow [Your first review](/docs/first-review).

Keys and tokens stay on your machine — details in [Privacy & data](/docs/privacy-and-data). If the **Start Guided Review** button never appears, see [Troubleshooting](/docs/troubleshooting#no-start-guided-review-button).
