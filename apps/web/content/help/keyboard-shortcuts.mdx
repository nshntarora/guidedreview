# Keyboard shortcuts

Move through a guided review without leaving the keyboard. Focus must not be in an editable field for most shortcuts.

<TocCard toc={toc} />

## Overlay navigation

| Shortcut | Action |
| --- | --- |
| `→` / `j` | Next unit |
| `←` / `k` | Previous unit |
| `Esc` | Close overlay (when not in a nested modal) |

Exact bindings can evolve with the product; the overlay footer and help affordances always reflect the current set.

## Diff view

| Shortcut | Action |
| --- | --- |
| View-mode chord | Toggle unified / split (see on-screen hints in the overlay toolbar) |

Selection-based commenting uses the mouse (or pointer) on diff lines; keyboard focus management keeps modals and the composer accessible.

## Marketing site

On [guidedreview.com](https://guidedreview.com):

| Shortcut | Action |
| --- | --- |
| `⌘/Ctrl` + `I` | Open install (Chrome Web Store) |
| `⌘/Ctrl` + `G` | Open the GitHub repository |

> **Tip.** Prefer keyboard navigation when reviewing large plans — it keeps context on the unit narrative instead of hunting scroll position on the PR page.
