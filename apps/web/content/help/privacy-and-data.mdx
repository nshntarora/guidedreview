# Privacy & data

Guided Review is designed so the extension does not phone home. Your PR content goes to **your** AI provider and (optionally) **GitHub** — not to a Guided Review backend. Short version also lives in the [FAQ](/docs/faq#do-you-track-anything).

## What the extension sends

| Destination               | When                                    | What                                                                                                                                                                                        |
| ------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Your AI provider**      | Starting / streaming a review           | Prompt built from the PR diff + schema instructions; API key in the Authorization header — [Configure AI provider](/docs/configure-provider), [How a review plan works](/docs/how-it-works) |
| **GitHub**                | Diff fetch, device OAuth, submit review | Diff/patch URLs, [OAuth device flow](/docs/connect-github#device-flow), [review API payloads](/docs/submit-review) you initiate                                                             |
| **Guided Review servers** | —                                       | **None** for extension product paths                                                                                                                                                        |

The background service worker is the only context that holds the API key and performs cross-origin LLM requests. Line-comment drafts are **not** sent until you explicitly [submit](/docs/submit-review).

## What stays local

- Provider choice, model, and API key (`chrome.storage.local`) — [Configure AI provider](/docs/configure-provider#where-settings-live)
- Active review session: diff, plan, step index (`chrome.storage.session`, keyed by `owner/repo#number`) — [Resume later](/docs/first-review#resume-later)
- [Draft comments](/docs/leave-comments) in the overlay until you submit
- GitHub tokens after [Connect GitHub](/docs/connect-github), until you disconnect

Closing the browser session clears session storage; local settings remain until you change or clear them. Session edge cases: [Troubleshooting](/docs/troubleshooting#session-and-resume).

## Website analytics

When enabled, the **marketing site** uses [PostHog](https://posthog.com) for page views and a few CTA clicks (install / star). Events go through a first-party path on guidedreview.dev — not through the extension. The extension does not embed that script and does not track review activity. Detail: [Cookies](/cookies) · [Privacy Policy](/privacy).
